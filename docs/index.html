### Server Components
Source: https://react.dev/reference/rsc/server-components

Server Components are a new type of Component that
renders ahead of time, before bundling, using
async/await to fetch data directly.

```jsx
export default async function Page() {
const data = await db.query('SELECT ...');
return <Dashboard data={data} />
}
```

Commands

Three ways to get the docs you need

🔍

ctx resolve alias: r

Search Context7's index for a library. Returns matching library IDs to use with docs.

📄

ctx docs alias: d

Fetch documentation for a library, filtered by topic and token limit. Auto-resolves library names.

⚡

ctx <lib> shorthand

Skip the docs command entirely. ctx react hooks just works — shorthand for ctx docs react hooks.

Use it everywhere

Plain text to stdout means it composes with everything

Why CLI instead of MCP?

MCP eats thousands of tokens just for tool definitions. ctx adds zero overhead.

ctx CLI Token overhead ~225 tokens
MCP GitHub MCP — tool definitions ~55,000 tokens
MCP List 50 Intune devices ~145,000 tokens
ctx CLI Same operation via CLI ~4,150 tokens

35x token reduction. Benchmarks by Jannik Reinhard (Feb 2026). MCP sends protocol metadata — ctx sends docs. For local models with 4k–8k context windows, that gap is the whole ballgame.

Features

⚡

Zero config

One command, no MCP server setup, no editor plugins, no API key required for basic usage. Just npx @theo-chinomona/ctx-cli.

📦

Zero dependencies

Uses only Node.js built-in fetch. No npm dependencies. No node_modules bloat. The entire install is ~10KB.

📚

Always current

Same indexed docs that power Cursor and Claude Code. Updated directly from library source repos — not stale scrapes.

🎯

Token control

Cap output with --tokens <n>. Essential for local models with tight context windows. No "surprise" token consumption.

🔗

Version-specific

Use exact Context7 IDs like /vercel/next.js or /websites/nextjs_15 to pin specific library versions.

🤖

Agent-ready

Inject accurate, up-to-date docs into agent prompts. Stop AI coding assistants from hallucinating APIs.
