Commands

Three ways to get the docs you need

Search

ctx resolve alias: r

Search Context7’s index for a library. Returns matching IDs to use with docs.

Fetch

ctx docs alias: d

Get docs by name or exact Context7 ID. Auto-resolves library names. Filter by topic and token count.

Shorthand

ctx <lib>

Skip the docs keyword entirely. ctx react hooks just works — shorthand for ctx docs react hooks.

Pipe it anywhere

Plain text to stdout means it composes with everything

Into AI coding agents
# Feed docs into Claude Code
DOCS=$(ctx nextjs "app router" --tokens 8000)

CLI vs MCP

MCP burns thousands of tokens on protocol overhead. ctx sends docs.

ctx Token overhead ~225 tokens
MCP GitHub MCP — tool definitions ~55,000 tokens
MCP List 50 Intune devices via MCP ~145,000 tokens
ctx Same operation via CLI ~4,150 tokens
35x token reduction. Benchmarks by Jannik Reinhard (Feb 2026). MCP sends protocol metadata — ctx sends docs. For local models with 4k–8k context windows, that gap is the whole ballgame.

Features

Zero config

No setup

One command, no MCP server, no editor plugin, no API key for basic usage. Just npx @theo-chinomona/ctx-cli and go.

Zero deps

10KB install

Uses only Node.js built-in fetch. No npm dependencies, no node_modules bloat, no build step. Ships as a single file.

Fresh data

Always current

Same indexed docs that power Cursor and Claude Code. Updated from library source repos — not stale scrapes.

Token control

Cap output

--tokens <n> caps response size. Essential for local models with 4k–8k context windows. No surprise token consumption.

Version pinning

Specific versions

Use exact Context7 IDs like /vercel/next.js or /websites/nextjs_15 to target specific library versions.

Agent fuel

Stop hallucinations

Inject accurate, up-to-date docs into agent prompts. AI coding assistants stop guessing APIs when you feed them real docs.
